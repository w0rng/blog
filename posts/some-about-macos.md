## Очистить dns кэш на macos

```bash
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
```

## Очистка прав доступа на macos

Иногда бывает, что удаленное приложение остается в разделе «конфеденциальность» и удалить его оттуда не получается.

Можно сбросить все права доступа и тогда оно пропадет:

```bash
tccutil reset All
```

> ❗❗❗это удалит все разрешения для приложения

## Получить заряд macos в терминале

```bash
pmset -g batt | grep -Eo "\d+%" | cut -d% -f1
```

## Открытие закладок в safari в новой вкладке

``` bash
defaults write ~/Library/Preferences/com.apple.Safari TargetedClicksCreateTabs -bool true
```

# Хоткей копирования текущего url в сафари

## 1. Создание AppleScript в Быстром действии

1. Открой **Automator** и выбери **Быстрое действие**.
2. В верхней части окна рядом с пунктом **Workflow receives** («Рабочий процесс получает») выбери **no input**(«без ввода») и **Safari** в списке приложений.
3. В панели слева в разделе **Утилиты** выбери и перетащи **Запустить AppleScript** в рабочую область.
4. Замени текст скрипта на следующий:

```
tell application "Safari"
 set theURL to URL of current tab of front window
 set the clipboard to theURL
end tell
```

1. Сохрани быстрое действие с именем, например, **Copy URL to Clipboard**.

## 2. Привязка комбинации клавиш к Быстрому действию

1. Открой **System Settings** («Системные настройки») и перейди в раздел **Keyboard** («Клавиатура»).
2. Выбери **Keyboard Shortcuts** («Сочетания клавиш»), затем **Quick Actions** («Быстрые действия») в левом меню.
3. Найди созданное быстрое действие **Copy URL to Clipboard** в списке и добавь к нему сочетание клавиш, например, `Command + Shift + C`.

Теперь, при использовании этой комбинации клавиш в Safari, URL текущей страницы будет копироваться в буфер обмена, аналогично функции в Arc Browser.

## Если возник конфликт с существующим хоткеем

1. Открой **System Settings** («Системные настройки») и перейди в раздел **Keyboard** («Клавиатура»).
2. Выбери вкладку **Keyboard Shortcuts** («Сочетания клавиш»).
3. В левом меню выбери **App Shortcuts** («Сочетания клавиш приложений»).
4. Нажми на кнопку **+** для добавления нового сочетания клавиш.
5. В поле **Application** («Приложение») выбери **Safari**.
6. В поле **Menu Title** («Название меню») введи точное название команды — **Начать выбор элементов**.
7. В поле **Keyboard Shortcut** («Сочетание клавиш») назначь новое сочетание клавиш, которое не будет конфликтовать с твоей комбинацией `Command + Shift + C`, или оставь это поле пустым, чтобы отключить команду.
8. Нажми **Add** («Добавить»).
